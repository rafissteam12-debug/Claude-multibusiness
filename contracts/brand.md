# Brand contract

- Umbrella: **Ablaufwerk**. Product: **Belegbrücke**. Presenter: **Ada** (illustrated, AI-generated, always disclosed).
  Names are working names until a trademark check; keep them in one place (`site/config.py`, `app/settings.py`) so a rename is one edit.
- Language: German. Website and app use "Sie". Instagram uses "du".
- Colours: teal `#0F4C5C` (primary), dark teal `#0A3540`, off-white `#F7F5F0` (background),
  white `#FFFFFF` (cards), ink `#17262B`, body `#33453F`, muted `#55635F`, line `#DAD6CC`,
  signal orange `#B4410B` (one accent per view: the key number or the main action),
  success `#1E7A55`. Text contrast >= 4.5:1.
- Type: IBM Plex Sans (400/500/600/700), IBM Plex Mono for file names and codes.
  Self-host the font files (no Google Fonts requests: privacy). If unavailable, system-ui.
- Voice: precise, calm, a little dry. Short sentences. Every rule with a source.
  Never: hype words, "rechtssicher", "garantiert", fake urgency, invented numbers.
- Disclosure: "KI-generiert" badge on every Ada visual; bio line; Meta AI label on synthetic video/voice.
- Scope line (verbatim on site and app):
  "Belegbrücke ist ein technisches Werkzeug. Inhalt der Rechnung, Umsatzsteuer und Pflichten bestätigen Sie oder Ihre Steuerberatung. Keine Steuer- oder Rechtsberatung."
- Assets: `content/ada/` (artwork), offer page draft `site/offer-page.dc.html` (design reference only).
