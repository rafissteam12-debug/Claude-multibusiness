# Independent review — wave 4 (1 Nov 2026)

Reviewer: independent agent (built nothing here). Scope: CLAUDE.md hard rules, contracts, all folders,
running app (localhost:8000, APP_ENV=dev, heuristic mapping, no KoSIT/Mustang locally) and site (localhost:8080).
Test suite: `python -m pytest -m "not network"` → all passed. Nothing in the code was changed.

## Verdict

**Ready for "unpolished finished": NO.** The core works: realistic files convert to XRechnung that passes all
local layers, totals and mixed-VAT rounding are right, credit notes come out as 381, ownership/CSRF/CORS hold
against real cross-origin requests, the AI gets value shapes only, and content claims match their sources
(8 claims spot-checked, all supported). Five things must be fixed first: one upload can freeze the whole server,
`[prüfen]` notes reach real users (in a mail that is actually sent), the validity rule accepts invoices with an
unknown or non-compliant profile, there is no account deletion, and the BT-29 seller id is accepted but never written.

## What was verified (evidence summary)

- IDOR: user B → user A's job, job page, file, mapping page, mapping PUT, propose, conversion: all 404; anonymous file: 401.
- CSRF/origin: evil Origin, `Origin: null`, `Sec-Fetch-Site: same-site`, missing token, magic link without `bb_pre` token → all 403.
  CORS preflight answered only for the site origin on the 3 public endpoints; app endpoints have no CORS.
- Headers: CSP without inline script, XFO DENY, nosniff, `X-Robots-Tag` and "Testversion" banner on app and site.
- Messy CSV 1 (CP1252, `;`, title row, row-per-line, 7 %/19 % in one invoice, price `12,333`, negative credit-note row,
  Leitweg-ID, one row without BT-10): 3 of 4 valid; VAT 19 % on 134,50 = 25,56 and 7 % on 24,90 = 1,74 (half-up, correct);
  credit note 381 with positive amounts; missing BT-10 correctly rejected.
- Hard rules: no prices in site/app/mails (only `[[BUSINESS_ID_PENDING]]`), no "rechtssicher/garantiert" outside the
  "never use" lists, no BestBroker4U traces (only the disclaimer in README), no secrets in git, Ada disclosed in all
  posts, bio and all 18 slide SVGs, logs carry only exception class names.
- Sources opened: § 14 and § 27 Abs. 38 UStG, § 5 ERechV, BMF 15.10.2024 Rn. 7/25/30/31/36/40, IHK Köln (BMF 2025),
  IHK Lüneburg-Wolfsburg (2028 quote, ELSTER viewer), xeinkauf.de versions (3.0 until ≥ 31.07.2027, 4.0 preview Sept 2026),
  E-Rechnung Bund 3.0.1 news. All statements supported; one wording nuance (L5).
